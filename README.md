## Features & Highlights

### 1. Modern E-Commerce Catalog & Discovery
- **Rich Product Categories**: Premium Dry Fruits, Quality Spices, Handcrafted Chocolates, Artisanal Coffee & Fine Teas, Customer Favourites / Best Sellers, and Curated Celebration Gift Boxes / Hampers.
- **Alternating Sections**: Full-width luxury alternating section backgrounds (White `#FFFFFF` and Warm Neutral `#FAF8F6`) with compact mobile vertical rhythm.
- **Mobile Swipeable Carousels**: 100% native momentum horizontal swipe on homepage collections without arrow clutter.
- **Collection Pages (2-Column Grid)**: Dedicated product listing pages (`/dry-fruits`, `/chocolates`, `/bundles`, etc.) render a clean, vertical 2-column mobile grid with product descriptions visible.

### 2. Inquiry Cart & Direct WhatsApp Ordering
- **Inquiry Workflow**: Indicative pricing catalog; customers build their list and submit structured orders directly to Ganga Sales | Konatural via WhatsApp (+91 82003 66244).
- **Interactive Cart Controls**: Inline `Add` button transforming into `− QTY +` quantity controllers (maximum 10 units per item).
- **Persistent State**: Cart lines and quantities persist across navigation and local storage.
- **Customer Details Drawer**: Streamlined customer information intake (Name, Delivery Address, Notes) formatted cleanly for WhatsApp submission.

### 3. Responsive Header & Navigation
- **Desktop**: 3-part layout with mathematically centered navigation links, subtle matte maroon hover transitions, and active page pill indicators.
- **Mobile**: Left-aligned brand identity, compact cart count icon, and a slide-out mobile drawer with comfortable touch targets.

## Getting Started

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
